# Kiro CLI

Orca agent ID: `kiro`.
`worker-start --agent kiro-cli` returns `agent_unconfigured` and creates no terminal.
Permission default: none.
`--trust-all-tools` is forbidden on the launch argv.
Forbidden headless form: `kiro-cli chat --no-interactive`.

Shared model/effort resolution, readiness, and retry rules remain in
`../../SKILL.md`. This reference adds no claim about native model-pinning
support.
